# leetcode75-c-solutions
## Array / String
*  Merge Strings Alternately - 兩個字串合併，馬上聯想到用雙指針方式實作
*  Greatest Common Divisor of Strings - 看了網友提示才知道方向，先檢查兩個字串前後拼接是否相同，再用字串長度的最大公因數去找前綴
*  Kids With the Greatest Number of Candies - 簡單的判斷題，要先找最大數再去比較
*  Can Place Flowers - 判斷左右兩邊是否可以種花
*  Reverse Vowels of a String - 雙指針，當兩邊都是母音，就做交換
